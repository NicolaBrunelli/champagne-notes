# Champagne — archivio personale

Sito editoriale privato realizzato con Astro.

## Sviluppo locale

1. Installa le dipendenze: `npm install`
2. Avvia l’anteprima: `npm run dev`
3. Apri l’indirizzo mostrato nel browser.

## Pubblicazione

Quando il repository GitHub e il progetto Netlify saranno collegati, aggiungeremo l’accesso su invito e la pubblicazione automatica.
